MINIMUM SPANNING TREE

Run an algorithm

Both algorithms find a minimum-cost spanning tree for a connected, weighted, undirected graph.

P

Prim's Algorithm

O(V²) · Adjacency matrix
01

Starts from a vertex and repeatedly adds the cheapest edge connecting the current tree to a new vertex.

K

Kruskal's Algorithm

O(E log E) · Sorting + DSU
02

Sorts all edges by weight and accepts the cheapest edges that do not create a cycle.

    THE DAA CONCEPT

    Minimum Spanning Tree

    An MST is a subset of edges that connects every vertex in a connected, weighted, undirected graph, contains no cycles, and has the minimum possible sum of edge weights.
